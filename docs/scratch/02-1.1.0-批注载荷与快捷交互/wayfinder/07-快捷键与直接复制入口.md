# 快捷键与直接复制入口

- Type: research
- Status: resolved
- Blocked by: none

## Question

在 IntelliJ IDEA 2026.2 中，如何让用户通过 IDE Keymap 配置一个默认 `Option+C` 的“直接复制空批注”入口；它与现有“批注…”入口、系统/IDE 现有快捷键以及单光标和多光标选区条件之间有哪些必须在产品契约中体现的边界？

## Resolution

### 平台事实

- IntelliJ Action 可以在 `plugin.xml` 的 `<keyboard-shortcut>` 中按 Keymap 注册默认快捷键；`first-keystroke` 使用 Swing keystroke 语法。
- `$default` 会把快捷键加入所有 Keymap；也可以只为指定的 macOS Keymap 注册。`Option` 在 Swing/IntelliJ keystroke 中表示为 `alt`。
- 所有已注册 Action 都能在 IDEA **Settings → Keymap** 中搜索并由用户添加、修改或删除快捷键；IDEA 在用户绑定时显示冲突警告。
- 当前“批注…”Action 的职责是打开输入框。直接复制空批注需要独立 Action，才能拥有独立名称、启用条件和可配置快捷键，同时不改变浮动工具栏与右键入口的既有行为。
- 直接复制 Action 根据当前焦点的数据上下文决定输出：编辑器存在非空选区时生成批注载荷；编辑器无非空选区时可复制当前文件链接；文件树聚焦时可复制选中的单个文件或目录链接。触发后均不打开输入框。

### 依据

- [JetBrains Plugin Configuration File · keyboard-shortcut](https://plugins.jetbrains.com/docs/intellij/plugin-configuration-file.html#idea-plugin__actions__action__keyboard-shortcut)

### 后续决策

用户指定 macOS 默认快捷键为 `Option+C`。是否同时在 Windows/Linux 默认绑定 `Alt+C`，需要在“默认快捷键平台范围”票中锁定。

无选区文件或目录链接的精确输出由“无选区文件或目录链接复制”票锁定。
