# 多选区批注载荷组合规则

- Type: grilling
- Status: resolved
- Blocked by: ./04-Selection来源链接契约.md, ./05-Selected-text代码块与语言标识.md, ./06-User-comment代码块边界.md, ./09-多光标选区模型与排序.md

## Question

多光标快捷复制时，哪些非空选区进入载荷、按什么顺序输出、相同或重叠选区是否保留，以及多个选区应组成一个载荷块还是用 `---` 分成多个块？

## Resolution

### 决策树

- **有效选区**：只处理具有非空选区的 Caret；同一编辑器中没有选区的 Caret忽略。至少存在一个非空选区时操作可用。
- **排列顺序**：按 `CaretModel.getAllCarets()` 提供的视觉位置顺序输出 `Selection 1`、`Selection 2`……。
- **选区独立性**：不合并或去重相同、相邻及重叠选区；每个非空 Caret 分别生成一个编号 `Selection` 章节。
- **单块结构**：所有编号 `Selection` 章节位于同一个外层 block quote 中，Selection 之间不使用 `---`，不拆成多个完整批注块。
- **直接复制内容**：`Option+C` 输出上述单块多选区载荷，不输出 `User comment`。
- **原子复制**：先生成整份多选区批注载荷，再一次性写入剪贴板；全部成功或全部失败，不产生部分复制。
- **载荷 footer**：单光标和多光标载荷都在全部引用内容结束后追加一次 `---`，不属于外层 block quote。最后一个引用行与 `---` 之间保留一个空行，`---` 后再保留一个空行；字符串固定以 `---\n\n` 结束。

以上由用户确认；单块编号 `Selection` 结构覆盖此前用 `---` 分隔多个内部批注块的方案，但整份载荷底部固定保留一次 `---`，方便连续粘贴多份批注。
