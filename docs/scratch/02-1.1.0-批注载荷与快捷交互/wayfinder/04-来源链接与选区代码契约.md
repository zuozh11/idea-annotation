# 来源链接与选区代码契约

- Type: grilling
- Status: resolved
- Blocked by: ./02-Source可点击定位方案.md

## Question

单光标与多光标批注中，来源链接和所选文本应使用什么最小结构；是否保留 `Source`、`Selected text`、`Selection` 或编号标题？

## Resolution

### 锁定格式

- 删除 `Source`、`Selected text`、`Selection` 和 `Selection N` 标题。
- 每个非空选区只输出一条来源链接，下一行直接输出该选区的 fenced code block。
- 单光标只输出一组“来源链接 + 代码块”。
- 多光标按视觉顺序重复多组“来源链接 + 代码块”，相邻组选区之间用一个裸 `>` 行分隔，不编号。
- 链接目标固定为不带行号的本地绝对文件路径。
- 链接文字使用文件名，并按 1-based 选区行范围追加定位信息：
  - 单行选区：`<文件名> (line <行号>)`。
  - 多行选区：`<文件名> (lines <起始行>-<结束行>)`。
- 起止行计算继续沿用 `1.0.0` 规则：结束 offset 为排他值，按最后一个实际选中字符确定结束行，选区末尾换行符不得把下一行计入范围。
- 点击链接只要求打开目标文件，不要求直接跳到指定行；Agent 根据链接文字识别目标行或行范围。

### 单光标示例

````markdown
> [AnnotationEditorService.java (lines 59-61)](/Users/zuozhi/workspace/zuozhi/idea-annotation/src/main/java/com/zuozhi/ideaannotation/AnnotationEditorService.java)
> ```java
> EditorController controller = controllers.remove(editor);
> if (controller != null) {
>     controller.dispose();
> }
> ```
````

以上由用户确认；无标题结构覆盖此前统一 `Selection`/编号 `Selection` 的方案。
