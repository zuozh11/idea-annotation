# 选区整体缩进移除

- Type: grilling
- Status: resolved
- Blocked by: ./05-Selected-text代码块与语言标识.md

## Question

所选文本整体位于缩进层级中时，代码块应保留源文件绝对缩进，还是移除公共前导缩进并只保留选区内部的相对层级；空行、多光标和顶格内容如何处理？

## Resolution

- 每个非空选区在生成代码块前独立执行整体缩进移除。
- 以所有非空物理行共同拥有的最长前导空白前缀作为整体缩进，并从每个非空行开头移除该前缀。
- 先删除选区首部和尾部所有连续空白行（空字符串或只包含空格/Tab）。
- 剩余内容中的空白行不参与公共前缀计算，输出时统一保持为空行，不保留只用于整体缩进的空白；中间空白行仍保留其行边界。
- 如果任一非空行没有前导空白，则公共前缀为空，所选文本不去缩进。
- 只移除公共前导空白；各行额外缩进、内部空格、文本内容、行顺序和换行结构保持不变。
- 多光标时每个选区分别计算公共前导缩进，不跨选区合并计算。
- 来源行号仍按编辑器原始选区 offset 计算，不受输出文本去缩进影响。

### 示例

输入：

```java
        private void showSuccess(AnnotationContext context) {
            Dimension balloonSize = JBUI.size(120, 32);
            JBPopupFactory.getInstance()
                .createHtmlTextBalloonBuilder(...);
        }
```

输出（首部空白行被删除）：

```java
private void showSuccess(AnnotationContext context) {
    Dimension balloonSize = JBUI.size(120, 32);
    JBPopupFactory.getInstance()
        .createHtmlTextBalloonBuilder(...);
}
```

以上由用户确认。

### 前导空白行示例

输入：

```scss

                .createBalloon()
                .show(
                    new RelativePoint(
                        editor.getContentComponent(),
                        successPoint(context, balloonSize)
                    ),
                    Balloon.Position.above
                );
```

输出：

```scss
.createBalloon()
.show(
    new RelativePoint(
        editor.getContentComponent(),
        successPoint(context, balloonSize)
    ),
    Balloon.Position.above
);
```
