# 无选区文件或目录链接复制

- Type: research
- Status: resolved
- Blocked by: ./07-快捷键与直接复制入口.md, ./12-默认快捷键平台范围.md

## Question

当前编辑器没有非空选区，或文件树选中一个文件或目录时，`Option+C`/`Alt+C` 应从哪个 IDEA 数据上下文取得目标，并输出什么精确内容？

## Resolution

### 平台事实

- IntelliJ Action 可从当前 `AnActionEvent` 数据上下文取得一个 `VirtualFile`，也可通过 `VIRTUAL_FILE_ARRAY` 取得多选项；编辑器与 Project View 都会向当前焦点 Action 上下文提供相应文件信息。
- `VirtualFile` 同时表示文件和目录；具有真实本地文件系统来源时可以取得绝对 NIO 路径。
- 依据：[JetBrains IntelliJ Platform · Virtual Files](https://plugins.jetbrains.com/docs/intellij/virtual-file.html)。

### 输出契约

- **上下文优先级**：只使用当前焦点上下文，不读取其他失焦界面的残留选中项。
  - 编辑器聚焦且存在至少一个非空选区：生成已定义的单选区或多选区批注载荷。
  - 编辑器聚焦且不存在任何非空选区：复制当前编辑器对应文件的独立链接，不附加光标行号。
  - Project View 聚焦且选中一个或多个具有真实本地绝对路径的文件或目录：按显示顺序复制对应独立链接。
- **链接文字**：使用文件名或目录名。
- **链接目标**：使用不带行号的真实本地绝对路径，并按标准 Markdown link destination 规则输出。
- **精确字符串**：单项输出为一个前导 ASCII 空格、一条 Markdown 链接和一个尾随 ASCII 空格，即 `" " + link + " "`；多项输出不加首尾空格，使用 `links.join("\n")`。除多项之间的单个换行外，不包含其他换行、block quote、`Selection`、`User comment` 或 `---` footer。
- **文件示例**：` [SupplierProductAppService.java](/absolute/path/SupplierProductAppService.java) `。
- **目录示例**：` [idea-annotation](/Users/zuozhi/workspace/zuozhi/idea-annotation) `。
- **边界**：文件和目录可以混合多选；若任一选中项无真实本地绝对路径，或当前焦点上下文没有文件/目录，则整个 Action 不可用，不部分复制或静默忽略。

以上产品行为由用户确认；平台能力由官方文档核对。
