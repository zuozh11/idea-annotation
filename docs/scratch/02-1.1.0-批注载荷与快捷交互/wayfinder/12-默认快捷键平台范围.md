# 默认快捷键平台范围

- Type: grilling
- Status: resolved
- Blocked by: ./07-快捷键与直接复制入口.md

## Question

“直接复制空批注”是否只在 macOS Keymap 默认绑定 `Option+C`，还是同时在 Windows/Linux Keymap 默认绑定对应的 `Alt+C`；若默认组合与用户现有快捷键冲突，是否只依赖 IDEA Keymap 冲突提示和用户重绑？

## Resolution

### 决策树

- **macOS 默认键**：直接复制 Action 默认绑定 `Option+C`。
- **Windows/Linux 默认键**：直接复制 Action 默认绑定对应的 `Alt+C`。
- **Action 边界**：该快捷键只触发直接复制，不打开批注输入框；有非空选区时复制批注载荷，无选区但当前上下文能取得一个本地文件或目录时复制独立链接，其他场景不可用。
- **用户配置**：用户统一通过 IDEA **Settings → Keymap** 修改或删除快捷键，插件设置页不重复维护第二套快捷键绑定。
- **冲突处理**：依赖 IDEA Keymap 的冲突提示和重绑能力；插件不为 `Option+C`/`Alt+C` 与字符输入或其他 Action 的冲突增加额外兼容逻辑。

以上由用户确认。
