# 多光标批注交互

- Type: prototype
- Status: resolved
- Blocked by: ./05-Selected-text代码块与语言标识.md, ./06-User-comment代码块边界.md, ./08-输入确认与换行设置.md, ./09-多光标选区模型与排序.md

## Question

用户通过“批注…”入口处理多个非空选区时，应禁止进入、为所有选区填写一条共享批注，还是逐选区填写独立批注；输入框位置、选区切换和最终复制行为采用哪种最小且可理解的交互？

## Resolution

### 原型

[多光标批注交互原型](../prototype/multi-caret-annotation-prototype.html) 提供三个可切换方案：

- A：一次输入，同一评论应用到全部选区。
- B：按视觉顺序逐选区填写独立评论。
- C：在批量面板中同时填写多个独立评论。

### 用户选择

采用 **方案 A：共享一条评论**。

### 最终交互

- 多个非空选区中触发“批注…”时，只打开一个与现有单选区样式一致的内嵌输入框。
- 输入框显示在视觉位置最靠后的有效选区末行下方；所有原选区继续保留。
- 用户输入一条评论并确认后，按已锁定的视觉顺序生成一个包含多个编号 `Selection` 的批注载荷块。
- 非空共享评论只在所有 `Selection` 之后输出一次 `User comment` 代码块；空评论则省略整个 `User comment` 章节。
- 确认后整份单块载荷一次性写入剪贴板；成功后关闭输入框并保留选区，失败时保留输入框和评论供重试。
- 取消、`Esc` 或点击输入框外部关闭输入框，不写入剪贴板并保留所有选区。

以上由用户通过原型和后续格式确认；单次共享评论覆盖此前“把同一评论重复写入每个批注块”的方案。
