# IDEA 批注插件方案地图

## Destination

形成一套可直接进入 `to-prd` 的完整决策：明确 IDEA 中的批注入口、输入与反馈流程、批注载荷格式、来源定位、插件设置、支持范围和验收边界。

## Notes

- 本地图只规划，不实施。
- 每轮加载 `docs/CONTEXT.md`，统一使用“批注”和“批注载荷”。
- 以用户提供的 Codex 批注截图和既定 Markdown 格式为参考，选择满足当前需求的最小方案。
- 当前开发环境为 IntelliJ IDEA 2026.2.1；兼容范围由决策票确认，不直接视为最终要求。

## Decisions so far

- [IntelliJ 平台能力与兼容基线](./wayfinder/01-IntelliJ平台能力与兼容基线.md)：公开平台 API 可覆盖完整流程；首版技术基线采用 IDEA 2026.2、Java 25、Gradle 9.x 和 IntelliJ Platform Gradle Plugin 2.18.1。
- [批注入口与交互流程](./wayfinder/02-批注入口与交互流程.md)：采用所选文本右上角小胶囊和右键菜单双入口，共用就地输入浮层；成功后当前选区不立即重新显示胶囊。
- [批注载荷格式边界](./wayfinder/03-批注载荷格式边界.md)：内容逐行保持 Markdown 引用，选区保持原样，批注只去除首尾空白并允许为空，章节用裸 `>` 分隔，载荷以一个换行符结束。
- [批注来源定位规则](./wayfinder/04-批注来源定位规则.md)：`Source` 使用本地绝对文件路径并追加 1-based 单行或行范围；允许未保存内容，只支持来源明确的单文件、单选区编辑器，不可用时不显示入口。
- [支持范围与交付边界](./wayfinder/05-支持范围与交付边界.md)：首版面向 IDEA 2026.2+ 的本地文本文件，跨平台实现但只验收当前 macOS，并交付 Gradle 源码和本地安装 ZIP。
- [验收场景与失败反馈](./wayfinder/06-验收场景与失败反馈.md)：成功后抑制当前选区胶囊、取消后继续显示；复制失败保留输入并允许重试；首版以 macOS IDEA 2026.2.1 沙箱人工流程和安装 ZIP 为验收证据。
- [批注胶囊设置](./wayfinder/07-批注胶囊设置.md)：设置页提供默认开启的应用级胶囊开关；关闭胶囊不影响右键“批注…”入口。

## Not yet specified

无；当前可见问题均已形成决策票。

## Out of scope

- 直接把批注发送到 Codex、ChatGPT 或其他聊天窗口；当前目的地只要求复制到剪贴板。
- 批注持久化、历史记录、多条批注聚合与编号管理。
- 语音输入、截图附件、删除批注和像素级复刻 Codex 界面。
- JetBrains Marketplace 发布、签名和自动更新流程。
