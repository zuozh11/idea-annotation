# 批注胶囊设置

- Type: prototype
- Status: resolved
- Blocked by: ./02-批注入口与交互流程.md

## Question

插件设置应提供哪些首版选项，胶囊关闭后哪些批注入口继续可用？

## Resolution

- 在 IDEA `Settings / Preferences > Tools > IDEA Annotation` 提供插件设置页。
- 首版只提供一个应用级复选项：`显示选区批注胶囊`，默认开启并持久化保存。
- 设置变化立即生效：关闭时移除当前胶囊并停止为新选区显示胶囊；重新开启后，对下一次选区变化恢复显示。
- 该开关只控制自动胶囊，不控制编辑器右键菜单中的“批注…”；右键入口在有效单选区中始终可用。
- 首版不增加胶囊位置、尺寸、快捷键、载荷模板或项目级覆盖等其他设置。

设置页和胶囊开关已补入交互原型；原型状态只保存在内存中，正式插件使用应用级持久化配置。
