## Question

哪些用户操作和边界场景构成首版验收集，触发条件不满足或复制失败时需要呈现什么反馈，才能证明已完成既定批注流程而没有扩展范围？

## Resolution

### 关闭与失败行为

- **复制成功**：关闭输入浮层，短暂显示“批注已复制”；原选区保留，但当前选区不立即重新显示胶囊，直到选区变化。右键菜单仍可立即再次批注。
- **取消输入**：`Esc`、点击外部或“取消”关闭浮层，不写剪贴板；原选区保留，胶囊设置开启时继续显示胶囊。
- **复制失败**：输入浮层保持打开，用户内容不丢失，在浮层内显示“复制失败，请重试”；再次点击“复制”即可重试，不弹模态错误框。
- **条件不满足**：无选区、多个非空选区、Diff 编辑器或没有稳定本地路径时不显示批注胶囊，也不额外提示。

### 首版人工验收集

在当前 macOS + IntelliJ IDEA `2026.2.1` 沙箱中人工完成以下检查：

1. 本地文件单行选区显示胶囊；复制结果包含 `<绝对路径>:<行号>`、原选区和批注。
2. 多行选区显示 `<绝对路径>:<起始行>-<结束行>`；缩进、空行及逐行 `> ` 引用保持正确，末尾换行不扩大行号范围。
3. 多行批注保留内部格式并去除首尾空白；每个物理行都在 Markdown 引用块中。
4. 空批注可以复制，输出符合已确定的空批注格式。
5. 文件有未保存修改时仍可批注，所选文本取当前编辑器缓冲区。
6. 鼠标拖选和键盘扩展选区均能在选区稳定后于所选文本右上角显示小胶囊；单行和多行定位符合约定，靠近可视区域边缘时不会溢出；胶囊不抢焦点、不清除选区且尽量少遮挡内容。
7. 胶囊和右键菜单均能打开同一个输入流程；关闭胶囊设置后右键菜单仍可使用。
8. 点击胶囊后输入框立即获得焦点；成功、取消和失败分别符合上述行为。
9. 复制成功后当前选区不立即重新显示胶囊，选区变化后恢复；取消后胶囊继续显示。
10. 多个非空选区、Diff、无本地路径编辑器不显示胶囊且右键菜单无“批注…”；具有真实本地路径的 Scratch 可以使用。
11. `buildPlugin` 生成安装 ZIP；从 IDEA 设置页安装后能够完成以上流程。

### 验收证据边界

首版只要求上述 IDEA 沙箱人工操作结果，不要求格式化单元测试或完整 UI 自动化。源码工程和安装 ZIP 均属于交付物，但 Marketplace 发布、签名和自动更新不在验收范围内。
