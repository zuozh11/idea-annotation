# 支持范围与交付边界

- Type: grilling
- Status: resolved
- Blocked by: ./01-IntelliJ平台能力与兼容基线.md

## Question

首版插件需要支持哪些 IntelliJ IDEA 版本、操作系统和文件类型，并以本地安装 ZIP、源码工程或其他形式作为本期可验收交付物？

## Resolution

### 决策树

- **IDEA 版本**：首版最低支持 IntelliJ IDEA `2026.2`，设置 `sinceBuild = "262"`；不为 2026.1 或更早平台增加兼容处理。
- **操作系统**：实现只使用 IntelliJ Platform 与 Java 跨平台 API，不编写 macOS 专用路径逻辑。
  - 首版验收环境仅要求当前 macOS + IntelliJ IDEA `2026.2.1` 通过。
  - Windows、Linux 保持代码层面的可运行性，但在未实测前不声明已经验证。
- **产品范围**：只承诺支持 IntelliJ IDEA，不扩展或验证其他 JetBrains 产品。
- **文件范围**：支持 IDEA 中所有具有真实本地绝对路径的文本文件，不依赖 Java PSI、Java 插件或具体语言；来源和选区限制沿用“批注来源定位规则”。
- **本期交付物**：
  - 可继续开发的完整 Gradle 源码工程；
  - `buildPlugin` 生成、可通过 IDEA 设置页从磁盘安装的插件 ZIP；
  - 不包含 JetBrains Marketplace 发布、插件签名和自动更新。

本期完成以源码工程能够生成安装 ZIP，并在当前 macOS IDEA 2026.2.1 中走通既定批注流程为边界。
