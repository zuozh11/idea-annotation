# 批注入口与交互流程

- Type: prototype
- Status: resolved
- Blocked by: ./01-IntelliJ平台能力与兼容基线.md

## Question

在 IDEA 中，选中文本后应通过什么原生入口触发批注，输入框如何出现、聚焦、确认和取消？

## Resolution

### 用户选择

采用 IDEA 原生 **浮动式代码工具栏**中的“批注…” Action，同时保留编辑器右键菜单中的“批注…”入口。两个入口打开同一个批注输入流程。

批注输入框采用 Component Inlay，作为固定 520 逻辑像素宽的块级内嵌卡片显示在最后一个实际选中字符所在行下方。卡片左边缘优先与选区起点对齐，空间不足时收进编辑器当前可视区域；使用紧凑高度、当前编辑器背景和单层圆角边框。

### 最终交互流程

1. 用户形成有效文本选区后，IDEA 原生浮动式代码工具栏显示“批注…”；点击后通过当前 2026.2 平台实现立即隐藏工具栏。
2. 对有效选区点击右键时，菜单始终提供“批注…”。
3. 点击任一入口后，在选区末行下方显示块级内嵌多行输入框并立即聚焦。
4. `Esc`、点击输入框外部或“取消”关闭输入框，不写剪贴板，并保留原选区。
5. 点击“复制”后生成批注载荷、写入剪贴板、关闭输入框，并短暂显示“批注已复制”。
6. 复制失败时输入框与内容保持不变，并显示“复制失败，请重试”。
7. 同一编辑器同时只保留一个批注输入框。

### 平台能力

- Action 通过 `plugin.xml` 注册到 `Floating.CodeToolbar` 和 `EditorPopupMenu`。
- 输入框通过透明的全宽块级 Component Inlay 承载固定宽度卡片，卡片横坐标由选区起点和当前可视区域共同确定。
- 输入使用 `EditorTextField`，容器使用平台配色和圆角边框。

结论：入口、定位和输入样式使用平台原生能力完成；允许使用当前 2026.2 浮动工具栏实现优化打开后的隐藏行为。
