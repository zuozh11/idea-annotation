# 批注来源定位规则

- Type: grilling
- Status: resolved
- Blocked by: none

## Question

`Source` 应固定使用绝对文件路径还是项目相对路径；对未保存文件、Scratch、Diff 编辑器、非文件编辑器和多光标选区分别应允许、禁用还是给出提示？

## Resolution

### 决策树

- **Source 形式**：固定使用当前文件的本地绝对路径，并追加 1-based 选区行号：
  - 选区只涉及一行：`<绝对路径>:<行号>`，例如 `/project/src/Example.java:64`。
  - 选区涉及多行：`<绝对路径>:<起始行>-<结束行>`，例如 `/project/src/Example.java:42-45`。
  - 起始行取选区首字符所在行，结束行取选区最后一个实际字符所在行；编辑器的结束 offset 为排他值，因此按 `endOffset - 1` 计算结束行。选区末尾包含换行符时，不把下一行计入范围。
  - **未保存修改**：允许生成批注。`Selected text` 读取当前编辑器缓冲区，`Source` 仍使用对应文件的绝对路径，不要求先保存。
  - **可用编辑器**：首版只支持能够解析到真实本地绝对路径的单文件编辑器。
    - 普通本地文件：允许。
    - 能解析到真实本地路径的 Scratch：允许。
    - `LightVirtualFile`、临时预览或其他没有稳定本地路径的编辑器：不允许。
    - Diff 编辑器：即使两侧来自本地文件也不允许，因为当前单一 `Source` 无法无歧义表示左右来源。
- **选区数量**：只有一个非空选区时允许生成批注；存在多个非空选区时不合并，也不静默选择主选区。
- **不可用反馈**：不满足来源或选区条件时完全不显示“批注”胶囊，不额外显示禁用入口或提示。

实现判断应同时满足：当前编辑器关联有效本地文件、能够取得绝对路径、不是 Diff 编辑器，并且恰好只有一个非空选区。生成 `Source` 时必须同时读取该选区的起止 offset 并转换为上述行号格式。
