## Question

哪些用户操作和边界场景构成首版验收集，触发条件不满足或复制失败时需要呈现什么反馈？

## Resolution

### 关闭与失败行为

- **复制成功**：关闭内嵌输入框，短暂显示“批注已复制”，原选区保留。
- **取消输入**：`Esc`、点击外部或“取消”关闭输入框，不写剪贴板，原选区保留。
- **复制失败**：内嵌输入框保持打开，用户内容不丢失，显示“复制失败，请重试”，可再次复制。
- **条件不满足**：无选区、多个非空选区、Diff 编辑器或没有稳定本地路径时不显示“批注…”入口，也不额外提示。

### 首版人工验收集

在当前 macOS + IntelliJ IDEA `2026.2.1` 沙箱中人工完成以下检查：

1. 单行和多行有效选区在原生浮动式代码工具栏及右键菜单中显示“批注…”。
2. 点击任一入口后，圆角内嵌输入框显示在选区末行下方并立即获得焦点。
3. 单行与多行 Source 行号、所选文本缩进、空行、首尾空白和最终换行符合载荷规则。
4. 多行批注和空批注均可复制，输出符合固定 Markdown 格式。
5. 文件有未保存修改时，所选文本取当前编辑器缓冲区。
6. `Esc`、点击外部和“取消”均关闭输入框且不写剪贴板。
7. 复制成功、复制失败重试分别符合上述行为。
8. 多个非空选区、Diff、无本地路径编辑器不显示入口；具有真实本地路径的 Scratch 可以使用。
9. `buildPlugin` 生成安装 ZIP；从 IDEA 设置页安装后能够完成以上流程。

### 验收证据边界

首版只要求上述 IDEA 沙箱人工操作结果，不要求格式化单元测试或完整 UI 自动化。源码工程和安装 ZIP 均属于交付物，但 Marketplace 发布、签名和自动更新不在验收范围内。
