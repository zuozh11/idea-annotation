# 断点日志式批注编辑器 1.3.5 PRD

## Solution

Selection Annotation 的编辑器内批注输入区跟随 IntelliJ IDEA 断点“日志”编辑器的低干扰外观：标题位于输入框左上方，输入区使用平台主题的文本框背景、普通边界与小圆角；“取消 / 确定”和错误反馈悬浮在输入区底部，不再占用独立 footer。

## Requirements

- 英文标题为 `Comment:`，简体中文标题为 `评论：`，通过现有资源包维护。
- 输入区的背景、普通边界、文字、光标、选区、字体和缩放使用当前 IntelliJ Platform 主题与编辑器能力，不写死截图颜色或设备像素。
- “取消 / 确定”位于输入区右下角 overlay，错误信息位于左下角同层，文本内边距避免内容被遮挡。
- 正文输入区默认为两行高，输入或粘贴超过两行的内容时随文档行数自动增高，删除内容时自动收缩但不低于两行，并同步更新 block inlay 高度；右下角操作行不占用这两行正文高度。
- 空输入区只显示当前 Enter/Shift+Enter 配置的简短快捷键提示，不再显示 `Add an optional annotation…` 等输入引导文案。
- inlay 与断点日志编辑器一样锚定在选区下一行的第一个非空白字符，显示在该行上方；水平起点跟随该字符，宽度为 `min(500, 右侧可用宽度)` 且最少为 `200` 逻辑像素。
- 多 Caret 不改变批注载荷的 Selection 顺序；UI 定位单独按 `endOffset` 取视觉最下方的 Selection，再与单 Caret 使用完全相同的定位和宽度计算。通过 `offsetToVisualPosition()` 取选区底部的视觉行，再通过 `visualPositionToOffset()` 反查下一视觉行的真实锚点，避免折叠区和软换行将 Inlay 提升到选区上方。
- 批注 Component Inlay 使用 `showWhenFolded(true)`，保持多 Caret 选区下的可见 bounds；批注载荷使用创建时保存的完整多选区上下文。
- 失去焦点时保留批注编辑器，只通过“取消”、`Esc`、确认成功或编辑器释放关闭。
- 每个编辑器同时只保留一个批注 UI；再次触发批注时先关闭旧 UI，再使用当前选区打开新 UI。
- 批注 UI 存在期间，对本次批注上下文的全部 Selection 使用编辑器原生 Range Highlighter 绘制跟随主题的活动标题色边框，不改变文档、选区文字或批注载荷。
- 选区边框与批注实例共享生命周期：取消、`Esc`、确认成功、新实例替换、Inlay 释放或 Editor 释放时清理；复制失败保留输入时同时保留边框。
- 保持文件、目录与图片粘贴，资源链接打开，Enter/Shift+Enter 设置，Esc 取消，输入法组合态，失焦保留，失败保留内容和成功提示行为。
- 不改变批注载荷或独立路径链接的 Markdown 协议。

## Observable Difference

- 调整前：批注输入使用蓝色焦点描边的大圆角卡片，按钮位于独立 footer。
- 调整后：批注输入使用与断点日志编辑器同类的标题和低干扰输入区，操作悬浮于输入区右下角。
