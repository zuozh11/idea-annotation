# Selection Annotation

## 产品

**Selection Annotation**:
把 IntelliJ Platform 中的编辑器选区、文件或目录转换为带来源信息的 Markdown，并复制到剪贴板的插件。

**批注上下文**:
一次批注所引用的来源与用户选择内容。

**批注载荷**:
Selection Annotation 为表达批注上下文而生成的 Markdown 内容。

**独立路径链接**:
只表达一个或多个本地来源位置、不携带批注上下文的 Markdown 链接。

## 交付

**沙箱交接**:
插件进入隔离 IDE 环境后，把真实交互验收交给用户的验证阶段。

**稳定发布**:
把一个稳定版本交付为正式签名插件包并推进分发的过程。

**签名插件包**:
可由 IDE 安装的正式发布物；它证明发布物形成，不证明分发平台已经公开。

**Marketplace 上传接受**:
分发平台已经收到某个版本，但尚不能由此推断审核或公开状态。

**公开版本**:
分发平台已经允许用户公开获取的版本。
